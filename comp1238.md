# COMP 1238 - Data Management Study Notes

Key takeaways

## Week 1 - History
- One writing system can be used by many different languages
- Cuneiform is one of the earliest known systems of writing
- The Epic of Gilgamesh was preserved on ancient clay tablets

## Week 2 - Bits and Bytes
- A bit is a single binary digit (`0` or `1`), and 8 bits equal 1 byte
- Hexadecimal (base 16) provides a compact way to represent binary values
- Character encodings like ASCII and UTF-8 map numbers to readable text

## Week 3 - Git and GitHub
- Git tracks file changes over time through saved snapshots called commits
- Markdown (`.md`) uses lightweight syntax like `#` for headings and `-` for lists
- Repositories store project files along with their complete version history

## Week 4 - Editors and Search
- Relative links like `[COMP1238 Study Notes](comp1238.md)` connect pages inside the same repo
- Pressing `.` on any GitHub repository opens the browser-based `github.dev` editor
- Search patterns and keyboard shortcuts speed up navigating and editing text files

## Week 5 - Command Line (Linux/SSH)
- `ssh user@host -p 2220` connects securely to a remote server on a custom port
- `ls -a` displays hidden files whose names start with a dot (`.`)
- Using `./-` or double quotes (`"./file name"`) lets commands read files with dashes or spaces
